# 实施路线与接手清单

本文档用于帮助后续 AI 会话、Codex 新线程或人工开发者快速判断“当前做到哪了、下一步该做什么、哪些边界不能碰”。

## 1. 当前产品定义

- 产品名称：Bybit 桌面版量化交易控制端
- v1 只做桌面端，不交付 Web 端
- 前端职责是观察、控制、审计、干预
- 自动交易最终执行仍归量化层
- OpenClaw 只做编排、复盘、调参、任务执行与状态回写

## 2. 当前代码现状

### 已落地

- `apps/desktop`
  - 已有 React + TypeScript 控制端界面
  - 已用 Electron 作为当前桌面壳
  - 已有总览、行情、策略、回测、AI 调度、新闻事件、提醒中心、交易记录、AI 复盘、系统日志/审计页面
  - 已有本地 API 调用层与 fallback 数据
- `services/control-api`
  - 已有 FastAPI 本地控制服务
  - 已有 `ControlSnapshot`、`ChangeRequest`、`AgentJob`、`BacktestRun`、`ExecutionEvent` 等模型
  - 已有本地 JSON mock 状态仓储
  - 已有 `WorkspacePreferences` 工作台状态持久化
  - 已有 Bybit 公共 REST 行情适配
  - 已有 Bybit 私有 API 只读账户视图适配与本地配置入口
  - 已有真实交易 POST 链路的安全探测接口
  - 已有 OpenClaw 本地配置读取与状态探测
  - 已有基于 `unittest + uvicorn` 的集成测试

### 尚未落地

- 已接真实 Bybit 公共行情 API，也已接只读私有账户视图；但尚未接私有流和真实交易执行
- 尚未接真实量化执行引擎、风控引擎、回测引擎
- 尚未把 OpenClaw 接成真实生产任务流
- 尚未开始 Web 端

## 3. 当前目录职责

### `apps/desktop`

- 控制端 UI
- 页面路由与展示逻辑
- 查询本地控制服务
- 发起结构化操作请求

### `services/control-api`

- 当前阶段的本地控制接口适配层
- 返回控制端所需的统一结构化数据
- 承接变更请求、调度命令、手动交易、回测发起等操作
- 保存 mock 状态和审计事件

### `docs`

- 保存产品边界、架构、契约、开发约定、实施路线
- 后续如果新增模块或改变边界，必须同步改文档

## 5. 当前环境限制

- Python 环境是 3.9，因此后续新增后端模型时不要默认写 `str | None` 这类 3.10 语法
- OpenClaw 当前按本机已有系统接入，不要修改 OpenClaw 源码

## 6. 交付门槛

- 后续每一轮开发都要先做测试，再交付。
- 最低交付门槛不是“代码写完”，而是“代码写完且对应验证已完成”。
- 推荐至少执行：
  - `pnpm --dir apps/desktop build`
  - `pnpm --dir apps/desktop lint`
  - `python3 -m py_compile services/control-api/*.py`
  - `python3 -m unittest discover -s services/control-api/tests -p 'test_*.py' -v`
  - 受影响接口的实际请求验证
- 如果本轮改动涉及调度、交易、回测或审计链路，应该额外补关键流程联调。
- 如果有测试没跑，需要在交付时明确说明缺口和风险。

## 7. 后续优先级建议

### P1. 把 mock 控制服务替换成真实量化适配层

- 先接真实行情订阅
- 再接真实账户、持仓、委托
- 然后接真实交易执行
- 再接策略运行时与回测任务

### P2. 把 OpenClaw 接成真实编排链路

- 定义 `ChangeRequest -> AgentJob -> 状态回写` 的实际协议
- 增加任务取消、暂停、恢复、失败重试
- 增加 AI 复盘与策略提案落库

### P3. 补桌面壳能力

- 托盘
- 系统通知
- 窗口布局持久化
- 本地密钥/配置体验

### P4. 再考虑 Web 端

- 保持 API 契约和状态模型不变
- 在桌面端稳定后再复用到 Web

## 8. 后续开发的硬边界

- 不要把产品重新定义成“人工交易工作台”
- 不要让 OpenClaw 直接碰 Bybit 交易执行
- 不要绕过量化层风控
- 不要默认把网页登录入口改成 `bybit.com`
- 只要涉及网页登录、账户设置、API Key 创建，统一按 `https://www.bybit-global.com/`
- 只要涉及 API 调用或文档引用，要主动说明网页入口与 API 域名用途不同

## 9. 新线程接手建议

如果后续在新线程里继续开发，建议先让 AI 做三件事：

1. 阅读 `AGENTS.md`、`README.md`、`docs` 下 4 份文档
2. 说明自己这次只改哪一层
3. 先验证本地命令是否还能跑通，再开始改代码

推荐开场检查命令：

```bash
pnpm --dir apps/desktop build
python3 -m py_compile services/control-api/*.py
```
